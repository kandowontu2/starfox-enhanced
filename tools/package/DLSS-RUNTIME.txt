OPTIONAL NVIDIA DLSS / DLSS 4.5 SUPER RESOLUTION RUNTIME

These files are part of Star Fox Enhanced's Windows x64 application.
Official releases provide them in a separate optional Windows x64 add-on.
Extract its complete dlss folder beside starfox_pc.exe and restart the game.
No installer, NVIDIA App override or ReShade is required. The base game works
without this download. Custom source builds can still explicitly embed it.
Select DLSS or DLSS 4.5 in 3D OPTIONS on a compatible NVIDIA GPU and D3D12.
They are separate options, both OFF by default, and only one can be active.
Each offers Quality, Balanced, Performance and DLAA. Standard DLSS requests
the first-generation transformer (preset K); DLSS 4.5 explicitly requests
the second-generation transformer (preset M). They share this official runtime.
Preset M can be more expensive than K, especially on RTX 20/30 series cards.
This integration provides Super Resolution/DLAA, not Frame Generation or
NVIDIA Ray Reconstruction. The game's ray tracer is a separate implementation.

RenoDX, ReShade and the DLSS5 neural-rendering add-on are not supported or
included. Their former experimental menu/control integration has been removed.
The game disables the system-wide ReShade Vulkan layer for its own process;
it does not uninstall or reconfigure graphics tools used by other games.
