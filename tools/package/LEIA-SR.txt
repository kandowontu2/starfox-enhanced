Leia SR (Windows x64)

Install the SR Platform runtime/service provided for your display. The game
does not include its system drivers, service or proprietary runtime DLLs.

1. Keep starfox_leia_sr.dll beside starfox_pc.exe.
2. Move the game window onto the SR display. Use Extend, not Duplicate,
   in Windows display settings.
3. Select Renderer: GPU and GPU Backend: AUTO (or DIRECT3D 12).
4. In Options > Stereoscopic 3D, change OUTPUT to SR PLATFORM.
5. Enable Preview or start the game. AUTO selects D3D12 for this route.

DISPLAYXR LEIA is a separate optional route, requiring DisplayXR. Installing
SR Platform alone does not enable DisplayXR. Use OUTPUT: SR PLATFORM for
the same direct SDK route used by the agrofubris stereo build.
Windows x64 release packages also include optional upstream DisplayXR and
Leia plug-in installers under optional-runtimes/displayxr. They are never
run automatically; read that folder's README before choosing to install.
If DisplayXR cannot connect when selected in the menu, the previous OUTPUT
is preserved (including SR PLATFORM). The optional toggle shows UNAVAILABLE
and can be retried after installing or fixing the required runtime.

If unavailable, run Diagnose-Leia-SR.cmd and send Leia-SR-diagnostics.txt
and startup.log. The checker probes SDK initialization on each monitor;
success does not certify native weaving, tracking, image quality or refresh.
Failed initialization leaves ordinary 2D presentation available.
